创建 Skill 测试工作台

测试工作台将一个 Skill 来源、测试定义、运行配置、执行轨迹和产物绑定在一起，并由你在本地管理。

00 / 工作台初始化

按照下面四个步骤创建测试工作台。创建完成后，项目会显示在左侧列表中。

01

命名工作台

使用清晰的名称标识当前 Skill 测试项目，并方便在左侧项目列表中快速找到。

→
02

导入 Skill 来源

选择本地 Skill 文件夹，或者导入包含完整 Skill 文件的 ZIP 压缩包。

→
03

配置运行环境

填写用户管理的 Endpoint URL、API Key 和 Model ID，连接兼容的推理服务。

→
04

验证并进入

检查 Skill 结构和运行环境是否可用，验证通过后进入项目详情页开始测试。

本地优先设计 Skill 文件和测试数据保存在本机，当前 HTML 原型不会上传任何项目数据。
