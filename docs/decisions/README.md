# Architecture Decision Records

Use this directory for decisions that materially constrain implementation.

Name records with an incrementing identifier:

```text
0001-use-postgresql.md
0002-use-sse-for-run-events.md
```

Each record should contain:

```text
# Decision title

Status: proposed | accepted | superseded
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives
## Consequences
```

Do not use an ADR for routine implementation details that can be changed within one module.
